# Vaccine-boosters
Code associated with paper: 
Deaths averted by vaccination due to reduced transmission can exceed those from direct protection of vaccinated individuals
There is one main code file: Booster_ms_githubF.R
To run this code you need to change a single line of code - the setwd() line. Just add the location where you place all the .csv files.
Note that the code Booster_ms_githubF.R reads in three .csv files (Figure3ABC2.csv, FracImmune.csv, VE_D_over_time.csv) that were created by two other scripts that take a long time (overnight) to run: VE_over_time_transmission.r and VE_over_time_death.r. You only need to run these R scripts if you want to recreate the three .csv files.
